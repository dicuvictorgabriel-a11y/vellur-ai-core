VELLUR · Models

Models

Which AI answers chat, writes code and creates images, and what each one costs.

Who answers what

Each kind of work tries its models from top to bottom. The first one is used; the others are fallbacks (a paid fallback only if “Paid fallback” is on in GPU).

Models and capabilities

Discovered models are grouped by what they can actually do. Vision means the model can read images; Image generation means it can create them. A model is never used for a task it does not declare.

Image generation

Optional and off until an image-output model is configured. The model must declare image output; VELLUR does not guess. Paid images need confirmation and are capped per request.

Model providers

Keys are stored on the server and never shown again. Plan “free” = free tier (cost 0), “subscription” = flat monthly fee (counted in the budget), “per token” = pay as you go (tracked and capped by the budget).
